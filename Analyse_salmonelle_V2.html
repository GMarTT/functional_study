Prédiction du niveau de virulence et du pouvoir colonisateur de souches de Salmonelles à partir de données spectroscopiques infra-rouges

Adélina Joanita Anato, Stéphanie Bougeard, Emmanuelle Houard, Martine Denis

2022-09-14

1 Objectifs


Objectifs :

  • Prédiction du niveau de virulence de souches de Salmonelles à partir de nombre d’ondes,
  • Prédiction du niveau de pouvoir colonisateur de Salmonelles à partir de nombre d’ondes,
  • En tenant compte de la variabilité issue de différentes expériences (oct-20, avr-21, jan-22) et différents réplicats (5 réplicats au maximum par souche de salmonelle et par expérience).

Plus précisément :

  • 3 niveaux de virulence à prédire,
  • 4 niveaux de pouvoir colonisateur,
  • à partir de 501 nombre d’ondes issues d’analyses spectroscopiques infra-rouges,
  • 15 souches disponibles,
  • 5 réplicats (au maximum) par souche et par expérience, soit au plus 15 réplications pour une souche donnée.

7 Analyse exploratoire multivariée : analyse discriminante PLS

7.1 Objectifs

  • Visualiser s’il est possible de différencier les modalités des deux facteurs (i.e., virulence et pouvoir colonisateur),
  • Visualiser quels nombres d’ondes sont impliquées dans ces différenciations,
  • Prendre en compte et/ou visualiser l’effet dû aux expériences, souches et réplicats.

7.2 Méthode sélectionnée

Spécificité des données :

  • Y = Une variable à expliquer nominale (= pouvoir colonisateur ou niveau de virulence),
  • X = 501 variables explicatives quantitatives liées entre elles (NB : plus de variables que d’observations ; 501 versus 222),
  • Une structure des observations possiblement liée aux expériences (souches et réplicats).

Méthode exploratoire multivariée : Du fait des objectifs et des spécificités des données, la méthode PLS discriminante sparse et multigroupe est appliquée. En effet, cette méthode permet de :

  • Expliquer une variable (–> PLS) qualitative (–> discriminante),
  • A partir de très nombreuses variables quantitatives (–> sparse) potentiellement corrélées (–> PLS),
  • Avec une structure sous-jacente des observations (–> multi-groupe)
  • NB : Les nombres d’ondes sont considérés comme des variables quantitatives (analyse exploratoire sans tests associés).

Afin que tous les nombres d’ondes aient le même poids dans l’analyse, ceux-ci sont centrés (même moyenne = 0) et réduits (même écart-type = 1).

8 Analyse prédictive : modèles multivariés


  • Objectif : Prédiction du niveau de virulence et du pouvoir colonisateur à partir des nombres d’ondes,
  • Méthode : Apprentissage automatique (application de différents modèles de discrimination).

8.1 Modèles de prédiction

Un algorithme de machine learning évaluant 15 modèles multinomiaux possibles est appliqué 50 fois (contrainte : ces modèles doivent être robustes aux variables explicatives très corrélées entre elles). Les modèles sélectionnés appartiennent à différentes catégories statistiques :

  • Modèles linéaires généralisés régularisés (glmnet = sparse et ridge)
  • Modèles bayésiens : classifieur bayésien naïf (naive_bayes)
  • Modèles issus de l’analyse factorielle : analyse discriminante pénalisée (pda), analyse discriminante régularisée (rda), analyse discriminante locale (loclda), kernel PLS (kernelpls)
  • Modèles issus des arbres de classification : forêts aléatoires (rf, ranger), bagged CART (treebag), C5.0
  • Modèles de discrimination non-paramétrique : K plus proches voisins (kknn),
  • Support vector machine (svmLinear, ORFsvm)
  • Modèles issus de réseaux de neurones (nnet, mlpML)

8.1.1 Modèle pour prédire le niveau de virulence

nbsim <- 50
meth  <- c('glmnet', 'naive_bayes', 'pda', 'rda', 'loclda', 'kernelpls', 'rf', 'ranger', 'treebag', 'C5.0', 'kknn', 'svmLinear', 'ORFsvm', 'nnet', 'mlpML')

res.perf.test            <- array(NA , dim = c(length(meth), 4, nbsim))
colnames(res.perf.test) <- c('%BC.Global', '%BC.HV', '%BC.IV', '%BC.LV')
rownames(res.perf.test) <- meth


for (s in 1 : nbsim){
  
  print(paste("Simulation.", s)) 
  
  # Création des jeux de données d’apprentissage et de test
  trainIndex <- createDataPartition(Data$Caco2.Adh_Inv, p = 0.70, list = FALSE)
  Data.train <- Data[trainIndex, ]    # 70% des observations
  Data.test  <- Data[-trainIndex, ]   # 30% des observations
  
  # Modèle sur les données d'apprentissage avec optimisation des paramètres par 10-fold CV (non répété)
  set.seed(12345)
  control   <- trainControl(method = "cv", number = 10, p = .9, summaryFunction = multiClassSummary)
  mod.train <- lapply(1:length(meth), function(m) train(Caco2.Adh_Inv ~ ., data = Data.train[, -c(1, 2, 4, 5)], preProcess = c("center", "scale"), method = meth[m], trControl = control, ouput = F))
  on.exit(stopCluster)
  
  # Prédiction
  pred.test  <- lapply(1:length(meth), function(m) predict(mod.train[[m]], Data.test, preProcess = c("center", "scale")))
  
  # Performance des modèles
  perf.test  <- lapply(1:length(meth), function(m) confusionMatrix(reference = Data.test$Caco2.Adh_Inv, data = pred.test[[m]]))
  res.perf.test[, 1 , s] <- sapply(1:length(meth), function(m) perf.test[[m]]$overall[1])                         
  res.perf.test[, 2 , s] <- sapply(1:length(meth), function(m) perf.test[[m]]$byClass['Class: HV', 1])

for (s in 1 : nbsim){
  
  print(paste("Simulation.", s)) 
  
  # Création des jeux de données d’apprentissage et de test
  trainIndex <- createDataPartition(Data$IpecJ2.Adh_Inv, p = 0.70, list = FALSE)
  Data.train <- Data[trainIndex, ]    # 70% des observations 
  Data.test  <- Data[-trainIndex, ]   # 30% des observations 
 
  
  # Modèle sur les données d'apprentissage avec optimisation des paramètres par 10-fold CV (non répété)
  set.seed(12345)
  control   <- trainControl(method = "cv", number = 10, p = .9, summaryFunction = multiClassSummary)
  mod.train <- lapply(1:length(meth), function(m) train(IpecJ2.Adh_Inv ~ ., data = Data.train[, -c(1, 2, 3, 5)], preProcess = c("center", "scale"), method = meth[m], trControl = control, ouput = F))
  on.exit(stopCluster)
  
  # Prédiction
  pred.test  <- lapply(1:length(meth), function(m) predict(mod.train[[m]], Data.test, preProcess = c("center", "scale")))
  
  # Performance des modèles
  perf.test  <- lapply(1:length(meth), function(m) confusionMatrix(reference = Data.test$IpecJ2.Adh_Inv, data = pred.test[[m]]))
  res.perf.test[, 1 , s] <- sapply(1:length(meth), function(m) perf.test[[m]]$overall[1])                         
  res.perf.test[, 2 , s] <- sapply(1:length(meth), function(m) perf.test[[m]]$byClass['Class: HC', 1])  
  res.perf.test[, 3 , s] <- sapply(1:length(meth), function(m) perf.test[[m]]$byClass['Class: HIC', 1])           
  res.perf.test[, 4 , s] <- sapply(1:length(meth), function(m) perf.test[[m]]$byClass['Class: LC', 1])
  res.perf.test[, 5 , s] <- sapply(1:length(meth), function(m) perf.test[[m]]$byClass['Class: LIC', 1])

}
